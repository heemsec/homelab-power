# Contrast

Pairs used by Sky Blue. Each one is WCAG AA for normal text (4.5:1) or better.

| Pair | Colors | Ratio |
| --- | --- | --- |
| Text on the dark page | #FFFFFF on #0B1628 | 18.1:1 |
| Muted text on a dark card | #A9C4D8 on #12233A | 8.7:1 |
| Navy ink on a sky button | #0B1628 on #7EC8F2 | 9.9:1 |
| Body text on the light page | #0B1628 on #F7FBFE | 17.4:1 |
| White text on a deep-blue button | #FFFFFF on #316AD7 | 5.0:1 |
| Navy ink on a mid-blue fill | #0B1628 on #3D8FE0 | 5.3:1 |

Mid blue is only a large fill. White text on mid blue is about 3.4:1, so the banner and any mid-blue shape use navy ink instead.
