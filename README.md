# Homelab Power

Homelab Power is a static electricity-cost calculator for home labs. Add your devices, set a rate (or start from a typical regional average), and see daily, monthly, and yearly energy and cost. What-if tools estimate downtime, consolidation, and hardware upgrades.

The app runs entirely in the browser. It has no tracking and no backend. Your labs and settings are saved in `localStorage` on this device. A service worker caches the app so it works offline, and you can install it to a phone's home screen.

It is published with GitHub Pages from the repository root:

https://heemsec.github.io/homelab-power/
